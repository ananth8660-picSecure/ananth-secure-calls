## Overview

A PicSecure ecosystem project focused on audio/video calling integrations for Ionic and Angular applications.

## Engineering focus

- Real-time audio and video workflows
- Device microphone and camera permission handling
- Call lifecycle, connection state and reliability
- Mobile/web integration and clean application interfaces
